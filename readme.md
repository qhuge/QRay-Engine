# QRay Engine

A WIP raycasting game engine.

## Usage

Build both the QRayEditor.exe and the QRayRuntime.exe and make sure they are in the same folder.

Execute the QRayEditor.exe to open the editor. You may build your own map for your game by clicking the squares in the middle. 

Once you think you're ready click on File -> Build. Choose a build location for you game. (Please note that saving or loading in the editor does NOT work atm.)

A folder with your map and the game executable named testGame.exe is created at the location you chose earlier.

## Features

Currently only building simple maps is supported. More features coming soon!!!!!
