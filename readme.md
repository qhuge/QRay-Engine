# QRay Engine

A WIP raycasting game engine.

## Usage

Build both the QRayEditor.exe and the QRayRuntime.exe and make sure they are in the same folder.

Execute the QRayEditor.exe to open the editor. You may build your own map for your game by clicking the squares in the middle. 

Once you think you're ready click on File -> Build. Choose a build location for you game.

The game is built into a folder named "ExampleGame" by default, in the location you chose in the previous step.

## Features

You can change the resolution and title of your game from settings menu (File -> Settings)
